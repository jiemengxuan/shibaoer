# 事宝儿 · 我的工作与生活事项管家

一个完全离线、数据只存在你自己手机上的待办应用。部署到 GitHub Pages 后，用 iPhone 的 Safari 打开网址并「添加到主屏幕」，就能像原生 App 一样使用（有独立图标、全屏显示、断网也能用）。

## 功能一览

- **事项列表**：打开即见全部事项，支持按 状态 / 分类 / 紧急程度 / 长期程度 / 大项目 筛选，支持关键词搜索
- **快速添加（自然语言）**：输入「明天交周报 #工作 加急」→ 自动识别日期、分类、优先级
- **双维度标签**：紧急（高/中/低）+ 长期（一次性/短期/长期持续）
- **详情页**：截止日期（逾期标红）、进度百分比、子任务拆解（列表卡片上点「分项」展开）、多张图片（自动压缩存本机）
- **@ 引用人名**：详情里输入 @ 弹出关系人名，选中后以靛蓝色高亮显示
- **关系人名管理**：维护同事、家人、爱人等（默认内置「张宇鑫 · 爱人」）
- **大项目管理**：如「数字船舶」，事项可挂在项目下
- **自定义分类**：内置 工作 / 日常 / 其他，可自行增删
- **未完成自动顺延**：昨天没做完的事项自动移到今天并标记「已顺延」，进度保留（可在管理页关闭）
- **统计复盘**：总事项、完成率环形图、最近 7 天新增/完成、分类与紧急度分布
- **JSON 导入 / 导出**：换手机或备份用「管理 → 导出 JSON」，换机后导入即可迁移

## 部署到 GitHub Pages（一次搞定）

1. 在 GitHub 上新建一个仓库（Public 私有均可，建议 Public 免费且无需登录浏览）。
2. 把本文件夹里的 **index.html、manifest.json、sw.js、assets/** 全部上传到仓库根目录。
3. 仓库「Settings → Pages」→ Source 选 `Deploy from a branch`，分支选 `main`，目录 `/ (root)`，保存。
4. 等 1~2 分钟，页面会显示你的网址：`https://你的用户名.github.io/仓库名/`。

## iPhone 添加到主屏幕

1. 用 iPhone 的 **Safari**（不是微信内置浏览器）打开上面的网址。
2. 点底部「分享」按钮 → 下滑找到「**添加到主屏幕**」。
3. 确认名称「事宝儿」→ 添加。桌面即出现带橙色图标的「事宝儿」，点开全屏使用。

## 数据说明

- 所有数据保存在浏览器本地（IndexedDB），**不上传任何服务器**，卸载页面/清缓存会丢失，请定期导出备份。
- 换手机：旧手机「管理 → 导出 JSON」→ 把文件发给新手机 → 新手机浏览器打开应用 →「管理 → 导入 JSON」。
- 更新应用：重新上传文件到 GitHub 仓库后，手机 Safari 打开网址刷新一次即可（自动顺延逻辑在每天首次打开时执行）。

## 本地预览（可选）

双击 `index.html` 即可在电脑浏览器预览全部功能（PWA 图标与离线能力需部署到 https 环境后生效）。
